# Autopl - Voice Controlled Dance Practice Player

## 1. 概要

本アプリは、**音声のみで音楽を操作できるダンス練習用のiPhoneアプリケーション**である。
ユーザーはスマートフォンを触らずに、イヤホンのマイクを通して音声コマンドを発話することで音楽を操作できる。

ダンス練習では激しい動きが多く、スマートフォンを手に持って操作することが困難である。また、スマートフォンがスピーカーに接続されている場合、操作のたびにスマートフォンの場所まで移動する必要があり、練習効率が低下する。

本アプリでは、イヤホンマイクを用いた音声操作によって遠隔から音楽再生を制御し、ダンス練習の効率を向上させることを目的とする。

---

## 2. 想定ユーザー

**主な対象ユーザー**

- ダンサー
- ダンスサークル
- ダンス練習を行う個人

**利用環境**

- 室内練習スタジオ
- 体育館
- 自宅

---

## 3. 利用シナリオ

1. ユーザーはスマートフォンをスピーカーに接続する
2. スマートフォンは部屋の端などに設置する
3. ユーザーはイヤホンを装着する
4. イヤホンのマイクに向かってウェイクワードを発話する
5. アプリが「聞き取り中」の表示と音でフィードバックする
6. ユーザーが操作コマンドを発話する
7. アプリがコマンドを認識し音楽を操作する

---

## 4. システムコンセプト

- 完全ハンズフリー操作（スマートフォンへの移動不要）
- 音声コマンドによる音楽操作
- ダンス練習に特化した10分割再生バーUI
- 音楽再生中でも音声コマンドを認識

---

## 5. 音声操作フロー

音声操作は2段階方式とする。

### Step 1: ウェイクワード

ユーザーはまず起動コマンドを発話する。

**デフォルト**： `はい行きます`（設定画面でカスタマイズ可能）

このコマンドによってアプリは音声コマンド受付モードに入る。
検出と同時に以下のフィードバックを行う。

- 画面: 「聞き取り中」の円形波形モーダルを表示
- 音: ピコーン（短い通知音）

### Step 2: コマンド認識

ウェイクワードの後、ユーザーは操作コマンドを発話する。

**タイムアウト**: 10秒（設定画面で変更可能）

**認識結果のフィードバック**

| 状況             | 画面                                       | 音                     |
| ---------------- | ------------------------------------------ | ---------------------- |
| コマンド認識成功 | モーダルが消える                           | ピコ音（クイズ正解系） |
| 認識失敗         | 「認識できませんでした」ポップアップ（小） | ブブ音（失敗系）       |
| タイムアウト     | モーダルが消える                           | ブブ音（失敗系）       |

### 音声操作フロー

```
待機状態
↓
ウェイクワード検出 → ピコーン音 + 「聞き取り中」表示
↓
コマンド受付（最大10秒）
↓
コマンド解析
↓ ─── 成功 → ピコ音 → 音楽操作 → 待機状態へ
↓ ─── 失敗/タイムアウト → ブブ音 → 待機状態へ
```

## 6. 機能要件

### 6.1 音楽ファイル管理

**インポート方法**

- Files app（iCloudドライブ等）から選択
- 他アプリ（LINE、AirDropで受信したファイル等）の「共有」メニューからAutoplへ直接インポート（Share Extension）

**対応形式**

- mp3 / wav / m4a

**永続保存**

- インポートしたファイルはアプリ内に永続保存
- アプリを閉じて再起動後も即座にアクセス可能
- 同一ファイルの重複インポートは不可

**起動時の復元**

- 前回開いていたファイルを自動で開いた状態にする
- 再生位置の復元は不要（再生位置は保存しない）

### 6.2 音楽再生機能

**基本操作**

- 再生 / 停止 / 次のファイル / 前のファイル / 最初から

**再生速度変更**

フッターの速度ラベル（例: `1x`）をタップするとポップアップで選択肢が表示される。

| 速度 | 倍率 |
|---|---|
| 0.25x | 1/4速 |
| 0.5x | 半速 |
| 0.75x | 75%速 |
| 1x | 通常（デフォルト） |
| 2x | 倍速 |

**10分割再生バーUI**

曲の総再生時間を10等分し、縦に10段表示する。

```
例）4分（240秒）の曲の場合

[======----------]  第1段  0:00 〜 0:24
[======----------]  第2段  0:24 〜 0:48
[======----------]  第3段  0:48 〜 1:12
       ...
[======----------]  第10段 3:36 〜 4:00
```

- 各段をタップすると、その区間の先頭から再生開始
- 再生位置は各段内でカーソルとして表示
- ダンス練習の特定パートへ素早く移動できる

### 6.3 音声操作

**ウェイクワード**

| 項目         | 内容                                |
| ------------ | ----------------------------------- |
| デフォルト   | `はい行きます`                      |
| カスタマイズ | テキスト入力で変更可能（設定画面）  |
| Phase 1実装  | テキスト入力のみ                    |
| 将来拡張     | 音声録音によるモデル登録（Phase 3） |

**コマンド一覧（デフォルト）**

| コマンド   | 動作                 |
| ---------- | -------------------- |
| 再生       | 再生開始             |
| 停止       | 再生停止             |
| 次         | 次のファイルへ       |
| 前         | 前のファイルへ       |
| 最初から   | 先頭から再生         |
| 音量上げて | システム音量を上げる |
| 音量下げて | システム音量を下げる |

すべてのコマンド語は設定画面でカスタマイズ可能。

**音声認識方式**

| 状態       | 動作                                                                                  |
| ---------- | ------------------------------------------------------------------------------------- |
| オンライン | 高精度クラウドAPIを自動使用                                                           |
| オフライン | オンデバイス認識にフォールバック + 「オンラインになると精度が上がります」の通知を表示 |

音楽再生中（スピーカーから音が出ている状態）でも音声コマンドを認識できるようエコーキャンセル処理を行う。

### 6.4 設定

| 設定項目         | 内容                                           |
| ---------------- | ---------------------------------------------- |
| ウェイクワード   | テキストで変更可能（デフォルト: はい行きます） |
| コマンド語       | 各コマンドのテキストを変更可能                 |
| タイムアウト秒数 | 変更可能（デフォルト: 10秒）                   |
| フィードバック音 | ON/OFFの切り替え                               |

すべての設定はアプリ終了後も保持する。

### 6.5 ダンス練習支援機能（将来拡張）

- 8カウント戻る
- 指定区間ループ
- 再生速度変更
- BPM解析
- 音声録音によるウェイクワードのモデル登録

## 7. 画面構成

### 7.1 画面一覧

```
Autopl
├── オンボーディング画面（初回起動時のみ）
├── 曲一覧画面
├── 再生画面
└── 設定画面
```

### 7.2 オンボーディング画面

初回起動時のみ表示。矢印付きで各UIの役割を説明する簡易チュートリアル。

**説明する内容（例）**

- 「↑ ここから音楽ファイルをインポートできます」
- 「← ファイルをタップすると再生画面へ移動します」
- 「↑ ウェイクワードを発話すると音声操作が始まります」
- 「← バーの各段をタップしてその位置から再生できます」

### 7.3 曲一覧画面

- インポートしたファイルの一覧を表示
- ファイルが1件もない場合は「まだファイルがありません。右上のボタンからインポートしてください。」を表示（Empty State）
- ファイルをタップすると再生画面へ遷移

### 7.4 再生画面

**表示情報**

- ファイル名
- 現在の再生時間 / 総再生時間
- 10分割再生バー（縦10段）
- 「聞き取り中」円形波形モーダル（1cm×1cm、Siri風、ウェイクワード検出時に表示）

**操作**

- 各段のタップで該当位置から再生
- タップで曲一覧に戻る（ナビゲーション）

### 7.5 設定画面

6.4 に記載の設定項目を編集できる画面。

## 8. 非機能要件

### 対応環境

| 項目                 | 内容                               |
| -------------------- | ---------------------------------- |
| OS                   | iOS 16以上                         |
| 言語                 | 日本語のみ                         |
| テーマ               | ライトモード / ダークモード 両対応 |
| バックグラウンド再生 | Phase 1では非対応                  |

### デザインシステム

| 項目 | 内容 |
|---|---|
| 設計指針 | Apple Human Interface Guidelines (HIG) https://developer.apple.com/design/human-interface-guidelines/ |
| UIライブラリ | React Native Paper (Material Design 3) https://reactnativepaper.com/ |
| 方針 | HIGのiOSらしいUX原則に準拠しながら、React Native Paperのコンポーネントで実装する |

### パフォーマンス

- 音声認識の応答遅延は体感できないレベルを目標とする
- ファイルのインポートから再生開始まで3秒以内

## 9. システム構成（技術）

### モバイルフレームワーク

React Native（Expo）

### 音声認識

- オンライン: クラウドAPIを使用（高精度）
- オフライン: オンデバイス音声認識（iOS標準 SFSpeechRecognizer）

### 音楽再生

- `react-native-track-player`（ネイティブオーディオAPI）

### ファイルインポート

- `expo-document-picker`（Files app連携）
- Share Extension（他アプリの「共有」メニューからのインポート）

### データ永続化

- `expo-secure-store` / `AsyncStorage`（設定・ファイル一覧・最終選択ファイルの保存）
